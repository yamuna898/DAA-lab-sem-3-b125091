# 📖 About This Repository

Welcome to my **Design and Analysis of Algorithms (DAA) Lab Portfolio**.

This repository contains the C programming solutions developed as part of **DAA Lab 01**. Each program explores a fundamental algorithmic concept such as asymptotic analysis, searching, sorting, recursion, probability, and algorithm optimization.

The primary objective of these laboratory exercises is to study how different algorithms behave under various input conditions, compare their computational efficiency, and understand the relationship between theoretical complexity and practical implementation.

Each program includes:

- Well-documented source code
- Detailed algorithm explanation
- Time and space complexity analysis
- Experimental observations
- Sample outputs
- Individual README documentation

# 💻 Compilation Instructions

### Using GCC (Linux / macOS)

Compile:

```bash
gcc filename.c -o program
```

Run:

```bash
./program
```

---

### Using GCC (Windows – MinGW)

Compile:

```bash
gcc filename.c -o program.exe
```

Run:

```bash
program.exe
```

---

### Using Code::Blocks

1. Open Code::Blocks.
2. Create a new C Console Project or open the existing source file.
3. Build the project (`Ctrl + F9`).
4. Run the executable (`F9`).
